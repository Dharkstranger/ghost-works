# Ghost works

A shared book between an artist and a gallery for every work on
consignment: where it is now, photos of its condition at each handover, sold
or not, and whether the artist's share was paid. A work nobody can account
for becomes a ghost until someone fixes it.

Built with [Kiro](https://kiro.dev) for Kiroween 2026. The plan Kiro builds
from is in `.kiro/`: the house rules in `steering/`, what to build in
`specs/ghost-works/`, and the automatic checks in `hooks/`.

"Put these works on Galleris" exports the works for
[Galleris](https://www.gallerismuseum.com), which puts a gallery's show
online.
